# Hospital_readmisson_risk_predictor
Technologies: Python, Jupyter Notebook, Pandas, NumPy, Scikit-learn, Matplotlib, Flask, Joblib, Random Forest Classifier
Developed a machine learning-based application using Python and Random Forest Classifier to predict hospital readmission risk.
Used Jupyter Notebook for data exploration, preprocessing, analysis, and machine learning model development.
Applied Pandas and NumPy for data processing and performed data preprocessing and feature handling.
Used Matplotlib for data visualization and analysis of the dataset.
Built a Flask-based web interface to collect patient information and generate prediction results.
Saved the trained model using Joblib for integration with the Flask application.
